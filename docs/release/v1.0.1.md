AI Model Inspector v1.0.1 is a free, open-source scientific instrument from LCC Research Lab. It is a macOS source-code release under Apache-2.0. Buying the *Adventures in AI* books is not required.

## Download (counted asset)

Download **`ai-model-inspector-1.0.1-macos-source.zip`** from the Assets list on this release page. That ZIP is the distribution LCC Research Lab tracks with GitHub’s `download_count`.

GitHub also offers an auto-generated “Source code” archive. Prefer the named ZIP above. The auto-generated archive is not our download metric.

A SHA-256 checksum file is attached: `ai-model-inspector-1.0.1-macos-source.zip.sha256`.

## Installation (macOS, one terminal)

You need Python 3.12 or 3.13 and Node.js with `npm` (Node.js 22 LTS tested). This is not a packaged macOS application.

```bash
unzip ai-model-inspector-1.0.1-macos-source.zip
cd ai-model-inspector-1.0.1
cd web
npm ci
npm run build
cd ..
./inspector-server.sh start
# optional, for console Start/Stop:
./inspector-controller.sh start
```

Open `http://127.0.0.1:8810`. The API listens on `127.0.0.1` only.

`./start-inspector-api.sh` is for foreground/debug use only. Do not run it as the first step of a normal install.

## What this release can do

- Inspect a Safetensors checkpoint you already have, when it is inside a configured directory.
- Measure stored weights and, for a compatible LoRA adapter, the effective update.
- Read the published Book Three Freshman results when the checkpoint files are not on the computer.
- Search public Hugging Face models. A download starts only after files are selected.
- List OpenAI, Anthropic, and Google Gemini model metadata for accounts whose keys are stored in the macOS Keychain. Keys are not shown. This does not run inference.

## Changes since v1.0.0

- Named release ZIP and checksum so downloads can be counted.
- Corrected single-terminal installation instructions (`npm ci`, then `inspector-server.sh start`).
- Reported software version set to 1.0.1.
- No change to measurement formulas or to the published Freshman validation record.

## Known limitations

- Windows and Linux are planned and are not supported platforms for v1.0.1.
- This archive does not include third-party model weights. Model files remain under their own licenses.
- Hugging Face discovery and cloud-provider listings contact those services. Checkpoint measurement reads local files and does not send them out.
- Python 3.14 can run the current suite and may report deprecation warnings from Starlette and FastAPI. Those warnings are not measurement failures.

v1.0.0 remains published and unchanged. Use this v1.0.1 asset for new installs when you want a trackable download.
